MEMS Catalog Parser v0.1
========================

Назначение
----------
Выгрузка авторизованного каталога https://b2b-mems.ru/catalog в Excel (.xlsx).
По умолчанию выгружаются только товары с фильтром «В наличии».
Опционально можно включить «Только основной склад Рязань».

Как пользоваться
----------------
1. Распакуйте архив полностью.
2. Запустите MEMS_Catalog_Parser.exe.
3. Выберите папку результата.
4. Нажмите «Начать выгрузку».
5. Откроется Chrome.
   - Парсер пытается один раз скопировать последнюю активную сессию Chrome в отдельный профиль.
   - Если MEMS попросит войти, авторизуйтесь вручную в открытом Chrome. Парсер продолжит автоматически.
   - Логин и пароль парсер не читает и не сохраняет.
6. После обхода страниц будет создан MEMS_в_наличии_YYYYMMDD_HHMMSS.xlsx.

Колонки
-------
Артикул, название, бренд/метка, наличие, цена, ссылка.

Диагностика
-----------
Logs\MEMS_Parser_LATEST.log — последний лог.
Debug\page_*.html и Debug\page_*.png — сохраняются при ошибке или изменении верстки.

Нагрузка
--------
Парсер не отправляет параллельные запросы. Каталог листается последовательно.
Пауза между страницами по умолчанию 500 мс и настраивается в окне.
